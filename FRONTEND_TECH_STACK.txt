===============================================================================
  MUTIARA WITH YOU - FRONTEND TECH STACK
  Penang LRT (Mutiara Line) Construction & Roadblock Tracker
===============================================================================

Versions listed are the ones installed in node_modules (from bun.lock), not
just the ranges in package.json.

The project is a frontend-only web app. There is no backend server or
database: all data (users, roadblocks, reports, announcements) is mock data
held in the browser by Zustand and saved to localStorage. The only network
calls go to free public map services (see section 9).

 1. RUNTIME & PACKAGE MANAGER
-------------------------------------------------------------------------------

BUN 1.4.4
  - Installs packages and runs scripts. Pinned in package.json:
    "packageManager": "bun@1.4.4". The lockfile is bun.lock.
  - Commands:
        bun install          install dependencies
        bun add <pkg>        add a dependency
        bun run dev          start the dev server  (next dev)
        bun run build        production build      (next build)
        bun run start        serve the production build (next start)
        bun run lint         run ESLint
        bunx tsc --noEmit    type-check the whole project
  - "trustedDependencies" lists sharp (Next.js image optimisation) and
    unrs-resolver (used by the ESLint import resolver). These are the only
    packages allowed to run install scripts.

NODE.JS 20.16.0
  - `bun run dev` starts the Next.js CLI, and the Next.js server itself runs
    on Node.js. Bun manages packages and scripts; Node runs Next.js.
  - @types/node 20.19.43 provides the Node type definitions.

 2. FRAMEWORK - NEXT.JS 16.4.3
-------------------------------------------------------------------------------

Routing: App Router (src/app/)
  - File-based routes:
        /                       Home dashboard (public)
        /map                    Live map, place search, route checker
        /reports                Submit a report / report history
        /profile                User profile and notification settings
        /sign-in, /sign-up      Auth pages, in the (auth) route group
        /admin                  Admin dashboard (KPIs, charts)
        /admin/post             Map editor: place and draw roadblocks, post
        /admin/reports          Review public reports
        /admin/announcements    Manage announcements
        /admin/profile          Admin profile
  - Route group "(auth)" shares one layout for sign-in and sign-up without
    adding "/auth" to the URL.
  - Nested layout: src/app/admin/layout.tsx wraps every admin page.
  - template.tsx wraps each page in a React <ViewTransition> so moving
    between pages animates instead of blinking.
  - Static metadata: `export const metadata` sets page titles and
    descriptions (12 files).

Bundler: Turbopack (the default for both dev and build in Next 16)
  - next.config.ts adds a Turbopack rule that runs every *.css file through
    @tailwindcss/turbopack 4.3.3. There is no PostCSS config.
  - The dev build goes to .next/dev, so `next build` can run while the dev
    server is still running.

Rendering features (next.config.ts)
  - cacheComponents: true
      Enables Cache Components. Pages you have visited stay mounted in the
      background (React <Activity>), so going back to a page is instant and
      keeps its state.
  - partialPrefetching: true
      Prefetches linked routes partially.
  - Server Components are the default. 'use client' is added only where a
    component needs hooks, Leaflet or browser APIs.
  - <Suspense> boundaries wrap components that read the URL with
    useSearchParams (required for static rendering).

Built-in modules used
  - next/link          Client-side navigation (14 files). Uses
                       transitionTypes={["nav"]} to trigger page transitions.
  - next/navigation    useRouter, usePathname, useSearchParams. Deep links
                       use URL parameters, e.g. /map?area=..., /map?mode=route,
                       /reports?tab=new&roadblock=...&at=...
  - next/dynamic       Loads the Leaflet maps with { ssr: false }, because
                       Leaflet needs `window` (map-explorer.tsx,
                       map-editor.tsx).
  - next/image         Optimised local images (logo, auth page art).
  - next/font/google   Self-hosts the Geist and Geist Mono fonts at build time
                       (CSS variables --font-geist-sans and --font-geist-mono).

 3. UI LIBRARY - REACT 19.3.0 / REACT DOM 19.3.0
-------------------------------------------------------------------------------

  - React Server Components plus Client Components.
  - <ViewTransition>    Animated page changes. The navbar and the mobile tab
                        bar have their own view-transition names, so they stay
                        still while the page content animates.
  - <Activity>          Used by Next.js Cache Components to keep pages alive.
  - <Suspense>          Loading boundaries for URL-dependent components.
  - Hooks used:
        useState, useEffect, useLayoutEffect, useMemo, useCallback, useRef,
        useReducer, useId, useSyncExternalStore
  - useSyncExternalStore drives three things in a hydration-safe way:
        use-mounted.ts   whether the app is running in the browser
        use-now.ts       a shared ticking clock for countdowns
        navbar.tsx       whether the page has scrolled
  - Custom hooks (src/hooks/):
        use-device-location.ts   device GPS position with permission and
                                 error states
        use-mounted.ts           client-only rendering guard
        use-now.ts               shared live clock
        use-stable-callback.ts   stable function reference for callbacks
  - @types/react 19.3.0 and @types/react-dom provide the type definitions.

 7. STATE MANAGEMENT - ZUSTAND 5.0.16
-------------------------------------------------------------------------------

  - One global store: src/store/useStore.ts.
  - It acts as the app's client-side "database" and session:
        - signed-in user and role (public / admin)
        - users and notification settings (email, WhatsApp, SMS, smart
          location)
        - roadblocks with closure segments, radius and travel modes
        - public reports and their review history
        - announcements and the admin's queue of pending changes
          (draft -> receipt -> post)
  - persist middleware (zustand/middleware):
        storage    createJSONStorage(() => localStorage)
        key        "mutiara-with-you", schema version 2
        skipHydration, with a manual rehydrate() after mount in
        ClientBootstrap (providers.tsx), so the server HTML and the first
        browser render always match
        custom merge that fills in settings missing from older saved data
  - rebaseSeed() shifts the mock dates so the data is always relative to
    today.
  - Selector hooks: useCurrentUser(), useSessionUserId(), and
    useStore(selector).
  - Seed data: src/lib/mock-data.ts and src/lib/seed-segments.ts (areas,
    places, 22 LRT stations, LRT routes, roadblocks, reports, users).

 9. MAPS & GEOSPATIAL
-------------------------------------------------------------------------------

leaflet 1.9.4
  - Map engine. Uses preferCanvas for fast drawing of many lines and circles.
  - leaflet/dist/leaflet.css is imported in stable-map.tsx.
  - @types/leaflet 1.9.22 provides the type definitions.

react-leaflet 5.0.0 and @react-leaflet/core 3.0.0
  - React components for map layers: TileLayer, Marker, Polyline, Circle,
    Tooltip and others.
  - stable-map.tsx is a custom map container built on @react-leaflet/core
    (createLeafletContext). It is safe under React Strict Mode and kept-alive
    pages.
  - Always loaded with next/dynamic { ssr: false }.

Map modules (src/components/modules/map/ and gov/)
  - live-map.tsx         public map: roadblock pins, closure lines, search
                         radius circle, route lines.
  - editor-map.tsx       admin map: place pins, draw closure stretches on
                         roads, drag to move.
  - base-layers.tsx      OSM tiles, the two Mutiara Line LRT routes, station
                         markers with tooltips, camera control (fit to
                         bounds with padding).
  - pins.ts              custom DivIcon pins (traffic-cone style, coloured by
                         closure type, with sun/moon/calendar badges) and an
                         icon cache.
  - segment-lines.tsx    road closure stretches drawn as polylines.
  - leaflet-fixes.ts     patch for a Leaflet 1.9 tooltip bug ("Cannot set
                         properties of null (setting '_source')").

External map services (free, no API key)
  - OpenStreetMap tiles       https://tile.openstreetmap.org/{z}/{x}/{y}.png
                              Base map, with © OpenStreetMap attribution.
  - OSRM routing              https://router.project-osrm.org
                              fallback: https://routing.openstreetmap.de/routed-car
                              The "nearest" and "route" services snap the
                              admin's drawing to real roads (src/lib/road-snap.ts).
                              7-second timeout per server, with fallback to
                              the next server.
  - Nominatim (OSM)           https://nominatim.openstreetmap.org/reverse
                              Turns the device's GPS position into a street or
                              area name (src/lib/locate.ts).

In-house geometry (src/lib/geo.ts; no Turf.js)
  - haversine distance, distance to a polyline, circle bounds, segment reach,
    route-versus-roadblock hit tests, the route suggestions shown by the
    route checker, and distance formatting.
  - src/lib/closure-type.ts works out a closure's type (full, partial, day,
    night, scheduled), including daily time windows.

 10. OTHER LIBRARIES & BROWSER APIS
-------------------------------------------------------------------------------

jspdf 4.2.1
  - Generates downloadable report PDFs (src/lib/report-pdf.ts).
  - Loaded only when needed, with `await import("jspdf")`, so it is not in
    the main bundle.

Dates and times: built-in Intl API
  - Intl.DateTimeFormat with locale "en-MY" and time zone "Asia/Kuala_Lumpur"
    (src/lib/time.ts). The fixed locale and time zone make the server and the
    browser print the same text, which avoids hydration errors.

Images
  - Construction photos from images.unsplash.com, shown with <img
    loading="lazy"> and a striped fallback if a photo fails (site-image.tsx).
  - Local assets in public/: logo/logo.png and sample PDFs in docs/.

Browser APIs used directly
  - Geolocation API        real device location for reports and "near me".
  - localStorage           persisted store (through Zustand).
  - fetch + AbortSignal.timeout   calls to OSRM and Nominatim.
  - View Transitions API   page transitions (through React <ViewTransition>).
  - ResizeObserver         positions the sliding navbar highlight.
  - MutationObserver       an inline <head> script removes attributes that
                           browser extensions inject (e.g. fdprocessedid),
                           so they don't cause hydration errors.
  - requestAnimationFrame  animated train on the station line, turned off
                           when the user prefers reduced motion.
  - matchMedia             detects prefers-reduced-motion.
  - File API / URL.createObjectURL   local previews of photos and PDFs.

 12. PROJECT STRUCTURE
-------------------------------------------------------------------------------

  src/
    app/                     Next.js App Router pages, layouts, template,
                             globals.css
      (auth)/                sign-in, sign-up (shared layout)
      admin/                 dashboard, post, reports, announcements, profile

        dashboard/           hero, station network line, roadblock feed,
                             subscriptions
        map/                 public map, search and route, roadblock panel,
                             Leaflet layers
        gov/                 admin: map editor, inspector, audit receipt,
                             announcement queue, report review, KPI cards,
                             charts
        user/                report form, report history, profile
    hooks/                   custom React hooks
    lib/                     types, mock data, geo maths, road snapping,
                             time formatting, closure types, PDF export,
                             utils
    store/                   Zustand store (useStore.ts)
  public/                    logo, sample PDFs, SVG icons

Conventions
  - Server Components by default; 'use client' only for hooks, Leaflet or
    browser APIs.
  - Every Leaflet component is loaded with next/dynamic { ssr: false }.
  - Mutiara Transit Blue theme (#1E40AF) throughout.
  - Accessible first: Radix primitives, keyboard-operable comboboxes, ARIA
    labels, visible focus rings, reduced-motion support, large touch
    targets.
